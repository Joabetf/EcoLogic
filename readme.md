# 🌱 Projeto Ecologic

O **Ecologic** é um sistema inteligente de monitoramento e controle de energia elétrica desenvolvido para o IFRN, alinhado ao conceito de **Smart Campus**. O projeto visa promover a eficiência energética, reduzir desperdícios e incentivar práticas sustentáveis por meio da integração de dispositivos IoT (Internet das Coisas) e uma plataforma de análise de dados em tempo real.

---

## 🎯 Objetivo

Desenvolver um sistema baseado em IoT para otimizar o consumo de energia no campus, permitindo o monitoramento em tempo real, o controle remoto de equipamentos (como iluminação e climatização) e a conscientização da comunidade acadêmica sobre práticas sustentáveis.

---

## 🚀 Funcionalidades

- **Monitoramento em Tempo Real**: Coleta de dados de consumo energético por meio de sensores.
- **Controle Remoto**: Possibilidade de ligar/desligar equipamentos elétricos de forma remota.
- **Alertas Inteligentes**: Notificações sobre excessos de consumo.
- **Visualização de Dados**: Plataforma IoT para análise e visualização do consumo energético.
- **Sustentabilidade**: Promoção de práticas conscientes e redução de desperdícios.

---

## 🛠️ Metodologia

O projeto utiliza a metodologia **Design Thinking**, com as seguintes etapas:

1. **Imersão**: Pesquisa exploratória sobre o problema e soluções existentes.
2. **Ideação**: Definição de requisitos técnicos e funcionais, arquitetura do sistema e especificação de componentes.
3. **Prototipagem e Teste**: Desenvolvimento de um MVP (Produto Mínimo Viável).
4. **Implementação**: Instalação do sistema em uma sala de aula do IFRN Campus Apodi para validação.

---

## 📊 Resultados Esperados

- Redução do consumo de energia elétrica.
- Conscientização da comunidade acadêmica sobre sustentabilidade.
- Modelo replicável para outros ambientes do campus.
- Contribuição para os Objetivos de Desenvolvimento Sustentável da ONU (ODS 12).
